# University Projects — MS in Applied Data Science

Coursework projects from my master's at the University of Chicago (September 2025 onward).

**Code only.** Datasets are not committed — every project README links to its source data
and explains where to place it. Model weights, virtual environments, cached outputs, and
raw data files are all excluded to keep this repository lean.

Most of these are team projects. Each README credits its contributors and links the
original team repository, which remains the canonical source and history.

| Project | Course | What it is |
|---|---|---|
| [drawdown-prediction](drawdown-prediction/) | Machine Learning II | Dual-stream LSTM + MLP forecasting 12-month equity drawdown |
| [tablesight](tablesight/) | Advanced Computer Vision | Three-model bake-off for hierarchical table extraction |
| [bayesian-dj](bayesian-dj/) | Bayesian ML | Music recommender using online Bayesian inference and Thompson sampling |
| [crude-oil-forecasting](crude-oil-forecasting/) | Time Series Analysis | ARIMA/GARCH analysis of 35+ years of WTI and Brent prices |
