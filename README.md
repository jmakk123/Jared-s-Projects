# Jared Maksoud — personal site

Static one-page site. No build step, no dependencies.

- `index.html` — all content
- `styles.css` — cream / maroon / gold theme
- `assets/` — project figures

## Local preview

```bash
python3 -m http.server 4321
```

Then open <http://localhost:4321>.

## Publishing

Served from this `gh-pages` branch via GitHub Pages
(Settings → Pages → Source: `gh-pages`, folder `/`).
